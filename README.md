**Study Case: Library Program**
This program's features consists of: Create, Read, Update, and Delete function, without using any built-in python libraries.

Table/Dictionaries: Books, Members, Transactions, Canceled Transactions, Head Librarian's User ID
Master Dict: Books (PK: ISBN); Members (PK: Phone and Member ID), User (PK: User ID)
Transaction Dict: Transactions (PK: Transaction ID), Canceled Transactions (PK: Transaction ID) 

Create Functions
Adding new records to each Dictionaries with pre-check the records before, to prevent any duplicate data.
Example: Create new records for books collection, new members and new transactions. 
Member ID and Transaction ID will be generated by running numbers.

Read Functions
Read all records from each Dictionaries, and show them to the User.
Example: Display books collection, members list, outstanding, canceled and all transactions list (with/without Member ID filter). 

Update Functions
Update fields (except Primary Key) of the specific record 
Example: Change books' title and author, members' name and phone number, update book-return date, update books stock

Delete Functions
Delete record from Dictionaries
Example: Remove Master Dictionary records (with limitation: never exist in Transaction Dictionary), remove transaction records (only accessible with head librarian's user ID)

Additional Features:
Pre-check date format, to prevent incorrect dates (e.g. 30 February, 31 April, etc.)
Transaction ID with running number, which compensated the canceled transactions ID
Hidden menu which only accessible with Head Librarian's user ID and password: Cancel Transactions, and Display all transaction records (include Canceled)

Limitations:
Since this program doesn't use library packages, Current date/timestamp can't be used.
Instead, a variable contains a date is being used.
This program doesn't feature financial transactions. 
This program only feature member's status (Regular or Premium Member), which result in the maximum quantity books that can be rented.
